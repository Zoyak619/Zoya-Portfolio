Project Background:

The purpose of this project is to build a command line interface (CLI) cafe app (Ppo-Cafe) in a busy business district. The cafe offers homemade lunches and drinks and the client needs a simple but functional sysytem to help manage products, couriers and customer orders. 


Client requirements:

* Maintain a collection of products and couriers
  The app allows users to view, add, update and delete products in both food/drink categories as well as the couriers. all data is sotred in dictionaries in lists and saved to .csv files.
  
* When a customer makes a new order, to create this on the system
  new customer ordered can be created, viewed, updated and deleted. Each order contains customers name, address, phone, chosen courer, status and items ordered.
  
* Update the status of an order i.e: preparing, out-for-delivery, delivered.
  All orderes can be updated to reflect different status such as preparing, out-for-delivery, and delivered.
  
* Upon exist off the app, all data to be persisted and not lost
  All data for products, orders and couriers is saved to .csv files each time the app is exists, so nothing is lost between app usage.
  
* Upon starting the app, to load all persisted data
  When the app loads it automatically loads all the lastest saved data from .csv files.
  
* Need to be sure the app has been tested and proven to work well
  The code is splict across modules with functions making it easier to write unit tests for each individual part later.
  
* Need to receive regular software updates.
  The app is modular and uses functions for every menu action, which makes it easyier to extend / imporove without having to re--write everything.
